##  Sobre este Repositório

Bem-vindo(a) à minha pasta central de estudos práticos! 

Este repositório serve como um laboratório pessoal onde consolido meu conhecimento técnico em **Ciência de Dados**. Aqui, o foco não é apenas rodar código, mas entender profundamente a estatística por trás dos modelos, praticar a limpeza de dados (que é 80% do trabalho) e aperfeiçoar a narrativa dos dados (*Data Storytelling*) para stakeholders.

Como venho de um background em **Análise de Sistemas**, busco aqui unir as boas práticas de engenharia de software com a matemática da modelagem preditiva.

## Estrutura de Estudos

Os projetos e notebooks estão organizados por temas para facilitar a navegação e a revisão de conceitos:

### 1️ EDA (Análise Exploratória de Dados)
*Foco: Entender o comportamento dos dados antes de qualquer modelagem.*
- Limpeza e Tratamento de Dados (Handling Missing Values, Duplicates).
- Detecção e tratamento de Outliers.
- Análise Univariada e Bivariada.
- Visualização de Dados com `Matplotlib` e `Seaborn`.

### 2️ Estatística Aplicada
*Foco: A base matemática para tomada de decisão confiável.*
- Testes de Hipótese (T-test, Chi-Quadrado, ANOVA).
- Distribuições de Probabilidade.
- Correlação vs. Causalidade.
- Análise de Variância e Viés.

### 3️ Machine Learning
*Foco: Criação de modelos preditivos e prescritivos.*
- **Supervisionado:** Regressão Linear/Logística, Árvores de Decisão, Random Forest, SVM.
- **Não Supervisionado:** K-Means, DBSCAN, PCA (Redução de Dimensionalidade).
- **Métricas de Avaliação:** RMSE, MAE, R², Curva ROC-AUC, Matriz de Confusão, F1-Score.
- **Otimização:** GridSearch e Cross-Validation.
